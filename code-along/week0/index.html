Week 0: getting set up

Cultural Data Analysis · Python Bootcamp

Ten steps through the tools we use all year, in the order of today's slides. By the end you will have a working Google Colab notebook connected to your Google Drive, a dataset downloaded with the terminal, and a first go at checking the work of an AI agent.

Each step says where to work (a code cell, a text cell, the terminal or a menu), what to do, and what you should see. Short commands you type yourself: that is how you learn them. Longer code you copy and run: you are not expected to understand every line of it yet. Each step says which. If what you see is different, that is worth a question.

    At home: Python on your own laptop

    Colab is all you need for this course. If you also want to work on your own laptop, these commands set up the same libraries the course notebooks use. You need Python 3.12 (from python.org, or Anaconda as shown in the slides). The install is several gigabytes because of the language and image models.

    Terminal (Mac or Linux):

    python3 -m venv cda-env
source cda-env/bin/activate
pip install -r https://raw.githubusercontent.com/goto4711/cdai/refs/heads/main/requirements.txt
pip install --no-build-isolation git+https://github.com/Kaggle/learntools.git
python -m nltk.downloader punkt punkt_tab stopwords
jupyter notebook

    Command Prompt (Windows):

    py -m venv cda-env
cda-env\Scripts\activate
pip install -r https://raw.githubusercontent.com/goto4711/cdai/refs/heads/main/requirements.txt
pip install --no-build-isolation git+https://github.com/Kaggle/learntools.git
python -m nltk.downloader punkt punkt_tab stopwords
jupyter notebook

    Two libraries also need a separate program: Week 5's text recognition needs Tesseract, and Week 3's tree drawings need Graphviz. On a Mac: brew install tesseract graphviz. The list of libraries is in the course repository: requirements.txt.

    Why two pip commands? The learntools checker used in the workshops can only be installed once pandas is in place.
