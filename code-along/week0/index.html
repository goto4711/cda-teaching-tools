Cultural Data Analysis · Python Bootcamp

Ten steps through the tools we use all year, in the order of today's slides. By the end you will have a Google Colab notebook linked to your Google Drive, a dataset downloaded with the terminal, and a first check of an AI agent's work.

Each step says where to work (a code cell, a text cell, the terminal or a menu), what to do and what you should see. Type short commands yourself to learn them. Copy and run longer code. You do not need to understand all of it yet. Each step says which. If you see something else, ask.

    At home: Python on your own laptop

    Colab is all you need for this course. For your own laptop, the easiest route is uv. It is free, installs its own Python and uses the same commands on Mac and Windows. The install takes several gigabytes for the language and image models, so give it time.

    1. Install uv, once. On a Mac, in the Terminal:

    curl -LsSf https://astral.sh/uv/install.sh | sh

    On Windows, in PowerShell:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    Close the Terminal or PowerShell window afterwards and open a new one, so that it finds uv.

    2. Make a folder for the course, open the Terminal (or PowerShell) in it, and set it up:

    uv venv --python 3.12
uv pip install -r https://raw.githubusercontent.com/goto4711/cdai/refs/heads/main/requirements.txt
uv pip install git+https://github.com/goto4711/learntools.git

    3. Start Jupyter, now and every time you come back to the folder:

    uv run jupyter notebook

    4. When a package is missing, install it with uv. Your course folder has no pip of its own, so plain pip install fails or installs into another Python:

    • In Colab, in a code cell: !pip install python-pptx
    • In your own notebook (started with uv run), in a code cell: !uv pip install python-pptx
    • In the Terminal, inside the course folder: uv pip install python-pptx

    Then run the cell again. The name you install can differ from the name you import. You install python-pptx but write import pptx.

    Two libraries also need a separate program. Week 5's text recognition needs Tesseract, and Week 3's tree drawings need Graphviz. On a Mac: brew install tesseract graphviz. The course repository lists all libraries in requirements.txt.
