Workshop: text and language models

Cultural Data Analysis · Week 4: Cultural Data Forms: Text

This week has the text workshop with transformer models, and a group exercise on language models and their APIs, with a choice of two notebooks.

First: save your own copy. The notebook opens from this website, so Colab does not keep your changes. Before you run anything, go to File → Save a copy in Drive and work in the copy that opens in a new tab. You find it later in Google Drive, in the folder Colab Notebooks.

1. Text workshop: transformers

Sentiment analysis of social media with Hugging Face: datasets, tokenisation (characters, words, sub-words), a baseline, fine-tuning a transformer model, a second case study (do two sentences mean the same thing?), and a tour of transformer applications: text classification, named entity recognition and text generation.

Open in ColabWeek4_Workshop.ipynb

Before you run anything:

  1. In the top menu, go to Runtime → Change runtime type and choose Python 3 with hardware accelerator T4 GPU.
  2. When asked, allow the notebook access to Google Drive: choose the same Google account you use for Colab and tick all the permissions. The notebook reads the models from the shared course cache (the CDA-CACHE shortcut you set up following the instructions on Canvas).
  3. Run the first code cell. It takes a while.

2. Group exercise: language models through their APIs

Work in groups of three or four. Your group chooses one of the two notebooks. Both start with the same 15 minutes on APIs: how researchers talk to a language model with a program instead of the chat window. The whole exercise takes about 50 minutes.

  • Everyone runs the notebook on their own laptop, but you work through it together.
  • Stop at the 💬 Discuss boxes and talk before you go on.
  • Each member hands in their own notebook, with the names of the group members at the top.

Option A: Are all LLMs the same? Whose history do language models tell?

Five models were asked for "20 important dates in world history" in English, Dutch and Chinese, ten times each. You compare their lists, check an LLM's coding of the events by hand, and ask whose history is missing.

Option B: Frozen in time. Can LLMs forecast world events?

A news video claims that AI models predicted the 2026 Iran war "spookily" well. You test this with forecasts from six models: where each model's knowledge stops, how good its probabilities are, and what happens when a model already knows the answer.

Both notebooks work without a key: they use answers we collected beforehand. With a free key you send the requests yourself.
