Build an app with UvA AI Chat

Cultural Data Analysis · Week 1: Python · a group exercise, about 30 minutes

An image is an array of numbers. Your group builds an app that shows this. You draw on a grid and see the grid as 0s and 1s. You write the specification, UvA AI Chat writes the code, and you test it.

Top row: [0, 1, 1, 1, 1, 0, 0, 0]

One laptop per group, logged in to UvA AI Chat (free, with your UvAnetID). Choose Claude Sonnet in the model menu.

1. Write the specification · 5 minutes

Say exactly what the app must do. Start from ours and add one thing of your own.

Make me a small web app that I can try here in the chat.

- An 8 by 8 grid of squares, all white at the start.
- Clicking a square switches it between white and black.
- Below the grid, show the grid as a Python list of lists: 0 for white, 1 for black, one row per line. It changes with every click.
- A button "Count black pixels" that shows how many squares are black.
- A button "Clear" that makes all squares white again.

Keep the code short and put a comment above each part, so that a beginner can read it.

2. Build it · 10 minutes

  1. Paste the specification into UvA AI Chat and try the app next to the chat. UvA AI Chat writes such apps in React, a JavaScript library.
  2. If something is wrong, do not edit the code. Describe the problem: "A square clicked twice stays black. It should turn white."
  3. Note every change you asked for.

3. Test it, and read the code · 5 minutes

Test, do not trust. Check by hand:

  1. Click the top-left square. Does the first number of the first row become 1?
  2. Click it again. Does it go back to 0?
  3. Draw a 3, as on the NumPy slide. Does the count match yours?
  4. Are there 8 rows of 8 numbers, top row first?
  5. Does Clear set all squares and the count to 0?
  6. Press Count black pixels, then click a square. Is the count still right?
  7. Read the chatbot's answer. What did it decide that you did not ask for?

Then open the code. It is JavaScript with React, but the ideas are this week's (see loops in four languages). Find the four patterns:

Data structureThe grid as a list of lists, [ ] inside [ ], often kept with useState.
SequentialThe loop that makes the 64 squares. In React it is often .map(…), which runs the same code for every item of a list.
Event drivenonClick says what a click does.
A decisionif chooses black or white (or ? :, a short if-else).

4. Together · 10 minutes

  1. Two or three groups show their app, the changes they asked for and what the chatbot decided on its own. Did the same specification give different apps?
  2. The class picks one new feature. Every group asks for it in the same words, for example:
    • a 16 by 16 grid,
    • a button that mirrors the picture from left to right,
    • greys from 0 to 16, as in the lecture's digits.
  3. Test it. Did every group get the same thing?

5. Take the app out of the chat · optional, at home

In UvA AI Chat, others can only see your app as a shared artifact. To use it anywhere else:

  1. Ask the chatbot: "Give me the same app as one standalone HTML file that runs in a web browser, with React and Babel loaded from a CDN."
  2. Copy the code into a plain-text editor and save it as pixel-grid.html. On a Mac, use TextEdit, choose Format → Make Plain Text and click Use .html if asked. On Windows, use Notepad and set Save as type to All files.
  3. Double-click the file. It opens in your browser, and you can send it to anyone. It needs an internet connection to load React.
  4. To put it online for free, rename the file index.html and upload it to a public GitHub repository. Under Settings → Pages, choose your main branch. The link appears after a minute or two. If you have never used GitHub, ask the chatbot to explain each step: "I have never used GitHub. How do I make a free account, a public repository and a GitHub Pages site for one HTML file, using only the website?"

Check that the new file works like your artifact, because the chatbot has written the code again.

Why. An app is made of this week's building blocks: a list, a loop, an event, an if. The chatbot writes them. You say what you want and check the result.
