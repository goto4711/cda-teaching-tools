Open in ColabWeek1_Workshop.ipynb

First: save your own copy. The notebook opens from this website, so Colab does not keep your changes. Before you run anything, go to File → Save a copy in Drive and work in the copy that opens in a new tab. You find it later in Google Drive, in the folder Colab Notebooks.

How it works

  1. Run the first code cell: it sets up the checks for the exercises.
  2. Work from top to bottom. Cells marked #Keep cell are ready to run; in the other exercise cells you write the code yourself.
  3. Below an exercise, run q1.check() (and so on) to check your answer. q1.hint() gives a hint and q1.solution() the solution: try first.
