Cultural Data Analysis

Code-along exercises and interactive tools for the lectures · Tobias Blanke, University of Amsterdam

Open the page for this week's lecture and code along with us. The lecture notebooks open in Colab; each week's workshop has a page with the instructions and a link that opens its notebook. In Colab, always start with File → Save a copy in Drive. The interactive tools are the demonstrations from the slides: try them again at home.
